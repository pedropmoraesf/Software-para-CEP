# CEPEXCEL — versão original para Excel

Esta pasta preserva o complemento original em formato `.xla` do projeto de graduação em Engenharia de Produção (Controle Estatístico de Processo), para referência e evolução futura.

**Aviso:** o complemento legado pode conter macros VBA; inspecione o código antes de habilitar macros em uma instalação do Excel. O arquivo original deve permanecer preservado, sem modificações.

O objetivo de evolução é avaliar compatibilidade com versões recentes do Excel e possíveis implementações para LibreOffice e Android.
